FOOTER NAVIGATION TEST

This test verifies all navigation links in the footer route to their correct pages.

Test Coverage:
    About Section:
        - About Us link
        - Contact link
    
    Shop Section:
        - All Products link
        - Earrings link (with category filter)
        - DIY Beads link (with category filter)
    
    Customer Care Section:
        - Shipping Info link
        - Returns link
        - FAQ link
    
    Legal Section:
        - Privacy Policy link
        - Terms of Service link
        - Cookie Policy link
    
    Social Media Links:
        - Instagram link (external)
        - TikTok link (external)

Instructions:
    This test is verified to work on:
        - Google Chrome VER 141.0.7390.123
        - Python Ver 3.13
        - Selenium 4.38.0

    Before running test:
        - Make sure dev server is not running 

    To run test, in command line:
        ./footer_test.bat

    Or double click on footer_test.bat

    The test will run automatically and test all footer navigation links.
    The browser will remain open until you press ENTER in the console.
    Check console output for detailed test results.

Expected Result:
    All test steps should pass and show checkmarks (✓) in the console output.
