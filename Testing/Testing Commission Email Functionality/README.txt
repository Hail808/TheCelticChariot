COMMISSION EMAIL PRODUCT OWNER TEST
This is a test for automatically writing an commission email to the product owner through the website itself.

Instructions:
    This test is verified to work on:
        -Google Chrome VER 141.0.7390.123
        -Python Ver 3.13
        -Selenium 4.38.0

    Before running test, make sure webhook and dev server are not already running

    To run test, in command line:
	    ./test-start.bat
	Or double click on test-start.bat
    This script will start the test program and start up the server and webhook

    The program will work automatically until the email is sent.
    Check the email address on both ends to verify Email API functions properly.
