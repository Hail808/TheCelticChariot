Customer Account Admin Page Access

This is a test to verify users logged into a customer account cannot access any admin pages
7Expected Result: Each time an attempt to access an admin page is made, the driver gets redirected back to the user_dashboard page


Instructions:
    This test is verified to work on:
        -Google Chrome VER 141.0.7390.123
        -Python Ver 3.13
        -Selenium 4.38.0

    Before running test, make sure webhook and dev server are not already running

    To run test, in command line:
	    ./test-start.bat
	Or double click on test-start.bat
    This script will start the test program and start up the server and webhook
